## Vanity 1.1 · Apple 风格重设计

iOS 与网页版按 Apple Human Interface Guidelines 整体重做。

### 设计
- 系统字体（SF Pro / 苹方）、大标题导航、分组列表、SF Symbols、毛玻璃材质
- 单一品牌色「玫瑰木」，到期状态使用系统橙 / 红，深色模式完整适配
- 新的 App 图标

### iOS
- 底部三个标签页：藏品、到期、设置；到期标签显示待留意数量
- 藏品页：品类相簿网格、全局搜索、「需要留意」卡片、一句话概览
- 分类页：分组列表、右滑记一次使用、左滑编辑/删除、长按大图预览、排序菜单
- 详情页：大图头部、「使用一次」按钮、按月分组的使用记录、期限进度条、每次使用成本
- 到期页：已过期 / 30 天内 / 之后 / 待补全 四组
- 编辑页：标准表单，可选择分类，开封时自动填入建议 PAO

### 网页
- 窄屏底部标签栏、宽屏侧边栏，与 iOS 结构一致
- 移除 3D 轮播和装饰字体，体积更小
- 可删除单条使用记录（可撤销），记住排序方式

### 安装
`Vanity.ipa` 未签名，需要用 AltStore、Sideloadly、SideStore 或 TrollStore 等工具用你自己的 Apple ID 签名后安装。
