## Vanity for iOS · 原生 SwiftUI 版

把网页版 Vanity 完整重写为原生 iOS 应用（iOS 17+，iPhone / iPad）。

### 功能
- 封面 3D 环形卡片轮播，11 个美妆分类，滑动带触感反馈
- 分类页：搜索、四种排序、左滑记一次使用、右滑编辑/删除、长按菜单
- 藏品详情：使用次数与历史、补记任意日期、上次使用、每次使用成本
- 到期计算与网页版一致：取「包装有效期」与「开封日期 + PAO 月数」中更早者，30 天内提示
- 到期提醒：到期前 7 天与当天 9:00 本地通知（可在设置中开关）
- 为藏品拍照/选图，照片只保存在本机
- 删除与记一次使用均可撤销
- 白天 / 夜间 / 跟随系统；iOS 18 上使用缩放转场
- JSON 备份导入导出，与网页版格式通用

### 安装
`Vanity.ipa` 未签名，需要用 AltStore、Sideloadly、SideStore 或 TrollStore 等工具用你自己的 Apple ID 签名后安装。
